# Лабораторна робота 2

**Тема:** Створення шаблонів (deftemplate) та впорядковані факти.

## Файли

- `task1_family.clp` – родинні зв'язки у вигляді фактів;
- `task2_airlines.clp` – мережа авіаліній (варіант 3): шаблон і факти;
- `task2_airline_rules.clp` – правила пошуку маршрутів авіаліній;
- `all_tasks_lab2.clp` – комплексний файл усіх завдань.

### Запуск

```
CLIPS> (clear)
CLIPS> (load "all_tasks_lab2.clp")
CLIPS> (reset)
CLIPS> (run)
```

> Файл `task2_airline_rules.clp` містить лише правила, тому перед ним слід завантажити `task2_airlines.clp`.
