# Експертні системи на базі CLIPS
Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

## Автор
- Студент: Святішенко Дмитро
- Група: ІН-32-2

## Структура репозиторію
- `Lab1/` – операції з фактами (assert, retract, facts);
- `Lab2/` – створення шаблонів (deftemplate) та впорядковані факти;
- `Lab3/` – формування бази правил (defrule) експертної системи;
- `Lab4/` – створення та використання функцій (deffunction);
- `Lab5/` – дерева рішень та логічне виведення;
- `README.md` – опис проєкту.

Кожна папка містить власний `README.md` з темою роботи, переліком файлів `.clp` і порядком запуску.

## Висновки
Під час виконання роботи я створив публічний GitHub-репозиторій, сформував структуру навчального проєкту з окремою папкою для кожної лабораторної роботи та завантажив до нього всі бази знань CLIPS, розроблені в лабораторних роботах 1–5: факти, шаблони (deftemplate), правила (defrule) та функції (deffunction). Тепер код зберігається в одному місці разом з історією змін, його можна переглянути з будь-якого пристрою і передати викладачу одним посиланням.

Я навчився створювати репозиторій, додавати файли та папки, фіксувати зміни комітами з коротким описом і оформлювати документацію мовою Markdown. Основна складність полягала в тому, що Git не зберігає порожні папки, — її вирішено створенням у кожній папці файлу `README.md` (введення шляху `Lab1/README.md` створює папку автоматично). Друга складність — частина файлів першої та другої робіт містить лише правила і не завантажується без відповідних шаблонів; щоб уникнути помилок при повторному використанні коду, у README відповідних папок вказано порядок завантаження файлів. Також перевірено, що всі файли збережені в кодуванні UTF-8, тому українські коментарі та повідомлення коректно відображаються на GitHub.
