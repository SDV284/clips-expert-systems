# Лабораторна робота 5

**Тема:** Дерева рішень, правила IF-THEN та логічне виведення.

## Файли

- `task1_prefix_notation.clp` – перетворення інфіксних виразів у префіксні, перевірка правилами;
- `task2_travel_expert.clp` – експертна система вибору подорожі (задача 3.5, варіант 3);
- `all_tasks_lab5.clp` – комплексний файл усіх завдань.

### Запуск

```
CLIPS> (clear)
CLIPS> (load "all_tasks_lab5.clp")
CLIPS> (reset)
CLIPS> (run)
```

> Програма веде діалог з користувачем: після `(run)` введіть метод оплати (`cash`, `check`, `account`) і тип відпочинку (`sea`, `ski`).
